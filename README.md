# XtreamHub releases

Installers for XtreamHub - see [Releases](https://github.com/Extra7-cis/xtreamhub-releases/releases/latest).

* **XtreamHub-Setup.exe** - Windows app (one-file installer)
* **XtreamHub-AndroidTV.apk** - Android TV / TV stick

Installed apps can update themselves: Settings > Updates (off until you turn it on).
